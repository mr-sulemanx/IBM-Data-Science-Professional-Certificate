# Course 1: What is Data Science?

## 📌 Description
An introduction to the field of Data Science, exploring what data scientists do, the roles within the field, and how data science drives decision-making across various industries.

## 🔑 Key Learnings & Topics
* Definition and importance of Data Science in the 21st century
* Roles and responsibilities of data scientists, data analysts, and data engineers
* Core concepts in statistical analysis and big data
* Real-world applications of data science in healthcare, finance, and technology
