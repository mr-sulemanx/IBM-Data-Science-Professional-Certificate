# Course 5: Python Project for Data Science

## 📌 Description
A mini-project course applying Python programming, web scraping, and data visualization to analyze real-world financial data.

## 🔑 Key Learnings & Topics
* Web scraping financial stock data using BeautifulSoup
* Extracting stock and revenue history using YFinance
* Plotting stock price and revenue dashboards with Pandas and Plotly
